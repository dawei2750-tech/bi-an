## 二、文件清理规则

### 2.1 应删除的文件（重复/无用/临时）

| 文件/目录 | 原因 | 位置 |
|-----------|------|------|
| `.DS_Store` | macOS 系统临时文件 | `src/common/locales/`、`src/js_sdk/` |
| `demo.scss` | uView 示例样式，非业务代码 | `src/common/` |
| `index.list.js` | 示例列表数据，非业务代码 | `src/common/` |
| `static/uview/example/` | uView 组件示例页面，生产不需要 | `src/static/uview/` |
| `static/swiper/` | 可能是示例轮播资源，需确认是否业务使用 | `src/static/` |
| `static/svg/` | 可能是示例 SVG，需确认 | `src/static/image/` |
| `Backend/Laravel5/` | 重复的 Laravel 备份目录，与主应用并行 | `Backend/` |
| `Backend/vendor/` | 依赖不应提交仓库，部署时 `composer install` | `Backend/` |
| `Backend/.env` | 含敏感信息，不应提交仓库 | `Backend/` |
| `Backend/.swo` `.swp` | vim 编辑器临时文件 | `Backend/` |
| `Backend/execute_currency.log` `haoshi.txt` | 运行日志/临时文件 | `Backend/` |
| `node_modules/` | 前端依赖，不应提交仓库 | 根目录 |
| `dist/` | 构建产物，不应提交仓库 | 根目录 |

### 2.2 需要更新的文件

| 文件 | 更新内容 | 原因 |
|------|----------|------|
| `package.json` | 固定 @dcloudio 版本为 `2.0.2-4070620250821001`，vue 固定 `2.7.14`，添加 cross-env | 当前版本混乱，2026版有 recyclableRender 兼容问题 |
| `manifest.json` | 替换 appid 为真实值，配置各端 appid | 当前为 HBuilderX 生成的占位 appid |
| `http.interceptor.js` | 替换 baseUrl 为真实后端域名 | 当前为占位符 `/api` 或示例域名 |
| `store/index.js` | 替换 baseUrl、baseDomain 为真实域名 | 当前为占位符 |
| `.env`（后端） | 重新配置数据库/Redis/ES 密码，不提交仓库 | 原仓库 .env 含示例密码，生产必须更换 |
| `vue.config.js` | 添加 transpileDependencies、postcss 配置 | 当前配置不完整 |
| `babel.config.js` | 添加 optional-chaining、nullish-coalescing 插件 | 当前可能缺少，导致可选链语法报错 |

## 三、代码缺失统计

### 3.1 后端缺失（本地项目完全缺失）

| 缺失结构 | 缺失原因 | 缺失功能 | 恢复方式 |
|----------|----------|----------|----------|
| **整个 Backend/ 目录** | 本地项目只改造了前端，未包含后端 | 全部后端业务逻辑：用户认证、交易撮合、钱包充提、行情推送、后台管理、代理商系统等 | 从原仓库复制 `Backend/` 目录，删除 `Laravel5/` 备份、`vendor/`、`.env`、临时文件后使用 |
| **数据库 SQL** | 本地项目无数据库文件 | 全部数据表结构：用户表、钱包表、订单表、行情表、配置表等（预计 100+ 表） | 从原仓库复制 `test123.sql`，整理为 `database/exchange.sql` |
| **部署文档** | 本地项目无部署文档 | 部署步骤、环境要求、Nginx 配置、Workerman 启动、定时任务配置等 | 从原仓库复制 `部署文档.md`，结合实际环境更新 |
| **后端 .env 配置** | 原仓库 .env 含示例密码，生产需重新配置 | 数据库连接、Redis、Elasticsearch、短信、邮件、区块链节点 RPC 等配置 | 参考 `Laravel5/.env.example`，按生产环境填写，不提交仓库 |

### 3.2 前端缺失/异常

| 缺失结构 | 缺失原因 | 缺失功能 | 恢复方式 |
|----------|----------|----------|----------|
| **`template.h5.html`** | 改造为 vue-cli 结构时可能未正确迁移 | H5 构建入口模板，影响 H5 打包 | 从原仓库 `uniapp/template.h5.html` 复制到前端根目录 |
| **`uni.scss`** | 需确认是否在 src/ 下正确存在 | 全局 SCSS 变量，uView 主题色、涨跌色等 | 从原仓库复制，检查 `$u-primary` 等变量配置 |
| **`postcss.config.js`** | 当前配置可能不完整 | PostCSS 插件配置（autoprefixer、postcss-comment 等） | 按 uni-app vue-cli 标准配置补全，autoprefixer 锁定 9.x |
| **`cross-env` 依赖** | 之前为绕过报错删除了 | 跨平台环境变量设置，Windows/Linux 统一构建脚本 | `npm install cross-env@7.0.3`，build 脚本恢复使用 cross-env |
| **`@dcloudio/vue-cli-plugin-hbuilderx`** | package.json 中可能缺少 | HBuilderX 项目结构兼容插件，处理根目录源码模式 | 添加到 devDependencies，版本与其他 @dcloudio 包一致 |
| **`@dcloudio/vue-cli-plugin-uni-optimize`** | package.json 中可能缺少 | 编译优化插件（Tree Shaking、代码分割） | 添加到 devDependencies，版本一致 |
| **`@dcloudio/uni-app-plus`** | package.json 中可能缺少 | App 端运行时，编译时需要（即使只发 H5） | 添加到 dependencies，版本一致 |
| **`@dcloudio/uni-console`** | package.json 中可能缺少 | 控制台增强，统一各平台 console 输出 | 添加到 dependencies，版本 `3.0.0-4070620250821001` |
| **`regenerator-runtime`** | package.json 中可能缺少 | async/await 运行时 polyfill | 添加到 dependencies，`^0.14.1` |
| **`@babel/plugin-proposal-optional-chaining`** | babel.config.js 可能缺少 | 可选链 `?.` 语法转译，@dcloudio 代码中使用 | 添加到 devDependencies，babel.config.js 中注册 |
| **`@babel/plugin-proposal-nullish-coalescing-operator`** | babel.config.js 可能缺少 | 空值合并 `??` 语法转译 | 添加到 devDependencies，babel.config.js 中注册 |
| **`UNI_CLI_CONTEXT` 环境变量** | vue-cli 模式下未自动设置 | uni-app CLI 上下文路径，不设置会报 `path undefined` | 在 build 脚本中显式设置 `UNI_CLI_CONTEXT=$(pwd)` |
| **`UNI_INPUT_DIR` 环境变量** | 源码在 src/ 目录，需显式指定 | 指定源码目录，默认是项目根目录 | build 脚本中设置 `UNI_INPUT_DIR=src` |

### 3.3 配置缺失

| 缺失项 | 缺失原因 | 影响 | 恢复方式 |
|--------|----------|------|----------|
| **`.gitignore`** | 本地项目可能没有 | node_modules、dist、.env 等会被误提交 | 创建标准 .gitignore，忽略 node_modules/、dist/、.env、*.log、.DS_Store |

4. **P3（重要）**：区块链节点对接、行情源配置、短信/邮件配置 → 核心业务可用
5. **P4（建议）**：冷热钱包、提现风控、监控告警、性能压测 → 生产级运营
